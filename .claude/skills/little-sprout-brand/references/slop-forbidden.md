# Slop 禁例（專案版）

從 LS-38（軌 C 7 輪、軌 D 12 輪、icon 5 輪）與 LS-46（11 輪）審查 comment 萃取。visual-reviewer 定義裡的通用十條（置中萬歲、均勻間距、模板版式…）仍適用；這份是**本專案實際中過槍**的形狀，每條附「為什麼在本專案是錯的」與機械判準。設計者自查、審查者逐條對照。

## 通過標準（沿用 visual-reviewer）

APPROVE 必要條件：≥3 輪迭代；reviewer 能自己寫出三個記憶點；通用十條＋本表全數無中槍或有充分理由；靈魂測試 pass（畫面有沒有「家」與「人」的溫度、照片該是主角的地方 UI 有沒有讓位）。「沒有明顯錯誤」＝ITERATE。
