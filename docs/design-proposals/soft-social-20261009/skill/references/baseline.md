# 基準與素材

方向來源為 2026-10-09 的 C「一起長大・柔粉精修」，見 [來源 issue #597](https://github.com/CLYEH/little-sprout/issues/597)。初始七屏方向獲使用者認可，新增五屏為延伸提案；不能視為逐屏核准或 App 實作決策。

本 skill 自帶 [家庭動態](images/home.png) 與 [寶貝成長](images/growth.png) 兩張原生匯出參考。兩圖均為 780×1688（2x）的靜態 PNG；家庭動態使用調色盤壓縮，原生設計與構圖不變。獨立複製整個 skill/ 時，這兩張參考與視覺規範仍可用。

完整提案隨包保留時，可從本檔定位：

- [原生 Pencil 稿](../../littlesprout-soft-social.pen)：只用 Pencil 官方工具存取，不直接解析不透明內容。
- [畫面與素材索引](../../SCREEN-MANIFEST.json)：十二屏的標題、節點、預覽路徑、尺寸及 SHA256，並記素材來源類型。
- [交付說明](../../README.md)：範圍、交付日期、全部交付內容的雜湊清單。
- [十二張預覽](../../exports/) 與 [原生稿必要素材](../../assets/)：移動提案時保持同層相對路徑。

單獨攜帶 skill/ 時，上列完整提案連結可能不在安裝範圍；請使用 skill 內附圖與 tokens，不能聲稱已讀取未提供的原生稿。此包不附私人網站或私人下載連結。

十二屏依序為家庭動態、回憶詳情、相簿、寶貝成長、飲食小記、家庭、加入照片、相簿內頁、通知、回憶搜尋、邀請家人、相簿尚無照片。

範例家庭為媽媽、爸爸、阿嬤三位成人與小禾一位寶貝。成人成員數與寶貝數分開表達；單篇範例的喜歡與留言數不是產品固定數量。邀請碼為視覺示意，不是真實憑證。

照片含既有儲存庫的示範素材及本輪 ImageGen 合成素材；以索引的來源類型為準，不全部標成新生成照片或真實使用者資料。食品插畫只用於飲食內容；空相簿使用簡潔相片圖示、文字與主動作，不引入舊紙相簿插畫。
