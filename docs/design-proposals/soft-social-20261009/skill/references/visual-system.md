# 柔粉社群視覺系統

下列數值對應核准的 390×844 邏輯尺寸畫板；780×1688 PNG 是 2x 匯出，不要把匯出像素當作字級或間距。

## 語意色彩

| primary | #F3C8D4 | 主要按鈕底色，小面積品牌重點 |
| primary-ink | #8E2447 | 主要按鈕字、動作、目前導覽 |
| selected | #F6DDE2 | 選取與陪伴提示底色 |
| canvas | #FAF3F5 | 畫面底色 |
| surface | #FFFFFF | 內容卡、輸入面 |

| muted | #715C65 | 時間、輔助描述 |

| milestone | #F8DECC | 杏桃生活小進步 |

| control-outline | #8A6470 | 有意義的控制外框 |

主要按鈕的 primary-ink/primary 對比為 5.624:1；control-outline/primary 為 3.389:1。separator 太淡，不拿它單獨辨識可操作輸入邊界。粉綠不是第二個品牌主色，也不直接承擔成功／安全狀態語意。

舊提案 JSON 的 `green` 欄位可能映射玫瑰色，只是沿革相容別名；新規範與新內容用上述語意名稱。

## 字體與形狀

Noto Sans TC：頁標題 22、成長大數值／食物名稱 26、正文及必要動作 17、次要時間等資訊 13。維持清楚的粗細層級；重要訊息不縮成 13 以硬塞進首屏。字型未隨設計包散布；缺字型時先說明替代影響，不能宣稱視覺完全一致。

白卡圓角 16、主要按鈕 12；頭像圓形，選取項目可用膠囊。群組內外常用間距 10–16，依內容建立節奏，不強制每個區塊相同高度。控制意圖容器至少 44×44，小圖示可以放在較大的容器內。

## 元件與狀態

- **貼文**：頭像＋作者／時間在上、短生活敘事、照片貼齊卡片、底部喜歡／留言。首屏可完整呈現一則貼文，不為塞第二則而犧牲字級。
- **導覽**：動態、相簿、寶貝、家庭四區保留文字。通知、更多等慣用次要圖示可不另加常駐文字，但目標大小仍足夠。
- **主要動作**：柔粉填色、玫瑰字、細控制外框。一個區塊建立清楚主動作，不把所有次要操作塗滿粉色。
- **選取／未讀**：用淺粉底或小點搭配文字／圖示／字重的差異，不只靠色相。
- **空白狀態**：保留頁面與相簿身分，簡短說明當前狀態、提供一個有情境的主要動作；空間不靠大型裝飾填滿。
- **搜尋**：查詢、篩選與結果脈絡可辨識。結果照片仍沿用白卡或簡單網格，不引入新視覺主題。
- **邀請**：看得出家庭名稱、對象與分享動作。畫面中的示意連結／QR 不冒稱可用的邀請憑證。

尚未形成核准範例的深色模式、平板版與新功能狀態屬後續設計範圍，不從這份手機視覺稿推導為已完成。
