# 萌芽日記 · 一起長大

以使用者認可的「C 一起長大・柔粉精修」為視覺基準：年輕、清楚、親近的家庭社群。借用現代社群的資訊層級與簡潔節奏，保留萌芽日記自己的暖粉配色與家庭照片。這個 skill 指導視覺，不增加功能或授權發布、開票、App 實作。

## 設計決策

- 柔粉是主要識別；粉綠只作成長資訊的小面積點綴。主要按鈕用柔粉底、深玫瑰字、細外框。不可因名稱有 Sprout 就改成綠色主題。
- 讓家人與照片先被看見：圓頭像、作者和時間、短敘事、照片、回應列。照片貼齊白卡邊緣；卡片外留呼吸空間。
- 維持平整、輕巧的介面。不要混入舊版傾斜拍立得、相紙框、角托、紙紋、巨大日期章、裝飾襯線字；也不要照搬 Facebook 的藍色或識別資產。
- 各頁依內容排版：動態用貼文卡、相簿用照片網格、家庭用成員列、成長用清楚數值與里程碑。不要把每頁都套成同一組彩色儀表板。
- 保留現有核准的等大蠟筆「萌芽日記」字標與相片疊圖示。食品插畫只放相關飲食內容；照片是主角，貼紙不佔據每張卡。

## 使用規範

新畫面先讀 [視覺 tokens 與元件](references/visual-system.md)。需要照片、原生稿或範例時讀 [基準與素材](references/baseline.md)，依實際檔案定位，不憑空宣稱已看過。

將需求映射到最接近的核准畫面，延伸版型與狀態即可；未提供的功能和流程不自行當成產品決策。新狀態的文案要交代對象與結果，例如是哪一本空相簿、要邀請到哪個家庭。文字用自然繁體中文，避免幼兒語氣與過量 emoji。

檢視實際原生匯出圖：照片裁切、文字層級、按鈕主次、同一家庭的姓名／張數／回應數、長文字與邊界是否一致。新底色與文字配對要驗對比；小字至少 4.5:1，有意義的控制邊界至少 3:1，動作目標至少 44×44。已核准配對可沿用，不以重複測試取代視看。

交付時區分原生 Pencil 稿、其匯出預覽與 ImageGen 概念圖。只描述實際檢視範圍與結果。使用者新的明確視覺指示優先於本基準。
