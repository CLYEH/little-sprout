### Blocker B1｜`scripts/hooks/large_file_read_guard.py:50-53,137`：Bash 側 H-LF(a) 擋掉票文與本 PR §1 明文保留的活性檢查用法

路徑是真的在用：現行 CLI 把 Agent 背景任務輸出寫在 `/private/tmp/claude-501/-Users-clyeh-little-sprout/<session>/tasks/<id>.output`（上述 94 條命令的路徑原文即此形狀），所以這條規則不是空包彈——它擋的正是 orchestrator 每天判活在用的那條路徑。而 Read 側對 `tasks/*.output` 是無條件 deny，連 `offset`／`limit` 都不給（實測 payload `{"tool_name":"Read","tool_input":{"file_path":".../tasks/abc.output","limit":100000}}` → deny），Bash 側又沒有任何等價逃生口 ⇒ 規則落地後 orchestrator **沒有任何方式**看到 agent 最近幾個 tool call。
