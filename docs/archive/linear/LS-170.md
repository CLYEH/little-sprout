## 範圍

1. `.claude/agents/ios-dev.md`：互動式驗證（模擬器對本機容器的任何多步驟人機操作）之前 `bash scripts/ops/supabase-lock.sh --hold "LS-<n> dev E2E" --max-minutes <=30`、收工 `--release`；持有期間自己的 `db reset`／`run.sh` 照常走 `--`；handoff 記持有時長；等待逾時（別人持有）不得刪 lock、改拆段。
2. `.claude/agents/merge-reviewer.md`：若 review 需要互動式實跑，同上（reviewer 多在主 checkout 跑——`--hold` 不得從主 checkout 用，改在票 worktree）。
3. 派工模板同步：`docs/COLLABORATION.md` §4-b 派工句與 §6 供給端段落補「互動式驗證先 hold」；orchestrator memory 由 orchestrator 自行更新。
4. **Gate（前饋必有反饋）**：`scripts/gates/agent-tools-check.sh` 規則表加兩條——`ios-dev.md`、`merge-reviewer.md` 必含 `supabase-lock.sh --hold` 字樣（缺即紅）；自測補案；掛 CI `rules`（已在）。
5. 「來源不明的一次 reset」：`patrol.sh` 的 lock 段已印持有者；本票順手在 `supabase-lock.sh` holder 檔加 `label`／worktree 已有——確認 `hold.log` 能回溯是誰，不夠就補一行 log（不擴 scope 做審計系統）。

## 不做
