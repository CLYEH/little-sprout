### MAJOR MJ-2 — 跨 parent 去重規則吃掉真缺陷：祖先兄弟只要「刻意小重疊」，底下的真碰撞就永久靜音

去重的**意圖**（檔頭 25-27 行）是「只報溢出自己容器撞到別家」，但用的**代理條件**是「祖先兄弟是否交集」。兩者不等價：祖先兄弟交集時，底下「後代溢出自己容器撞到別家」這個**新**缺陷同樣被跳過。自建反例實跑：

```

```

**具體失敗情境**：任何「照片與說明條共用 1pt 接縫」「卡片與陰影層重疊」這類會被白名單的刻意重疊之下，徽章／文字互蓋（正是 LS-67 R1「主鈕蓋住隱私揭露文字」那一類）永遠掃不到——而 `(a)` 那一筆會被分類成「刻意接縫」帶過。AREA_MIN=4 很容易達到：1pt×300pt ＝ 300 > 4。

**建議修法**：把跳過條件改成「**兩邊都沒溢出自己的祖先兄弟**」才算繼承交集——即 `a ⊆ sa && b ⊆ sb`（允差 TOL）且 `overlapArea(sa,sb) > AREA_MIN` 時才 `continue`。這完全保留「不重報繼承交集」的原意（不去重會 597×後代數，同意作者判斷），但不會漏掉溢出類。
