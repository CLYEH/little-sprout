* **I3** (a) `agent-tools-check.sh` 規則表補 `ios-dev` 一列（目前無 `tools:` 行＝放行，先佔位）；(b) `.claude/agents/visual-reviewer.md:10` 引用的 `export_nodes` 在本 repo 的 pencil MCP server 不存在（實測 tools/list 只有 browser／execute／get_app_state／get_style／read_skill）——改成實際可用的匯出方式（`execute` 內截圖 API），並在 brand-skill-check 或 agent-tools-check 加一條「agent 定義不得引用 server 沒有的工具名」的檢查（前饋必有反饋）。
