## 描述

來源：使用者 `/mcp` 授權 supabase 時遇 `Unrecognized client_id`（OAuth 動態註冊被 Supabase 端清掉、本機快取 client_id 失效）。使用者裁示換 PAT。

## Scope（比照 [LS-42](https://linear.app/little-sprout-app/issue/LS-42/harnessfigma-整合secrets-pattern唯讀-mcp官方-kit-參考資產) Figma 模式）

1. `.mcp.json`：supabase 由 http+OAuth 改 **stdio**——`@supabase/mcp-server-supabase@0.11.0`（pin）＋`--read-only --project-ref=mzkkkzbiejgvhwjyiokf`（唯讀與鎖定專案不變）；token 走 `SUPABASE_ACCESS_TOKEN` env（`source .env`＋`:?` fail-loud＋git-common-dir 路徑解析，值不進 repo、不進 argv）。
2. `scan-secrets.sh` 補 `sbp_` PAT pattern（自身免疫寫法）。
3. COLLABORATION §5 env 變數行＋§6「read_only」措辭＋§7 對照表同步。

使用者側動作：到 [supabase.com/dashboard/account/tokens](<http://supabase.com/dashboard/account/tokens>) 生 PAT → `.env` 加一行 `SUPABASE_ACCESS_TOKEN=sbp_...` → 重啟 session。走 hotfix 流程。
