## Scope（新 migration＋測試，走正常 feature 流程）

1. `public.rls_auto_enable()` **收權**：SECURITY DEFINER 函式目前可被 anon／authenticated 經 `/rest/v1/rpc/` 呼叫（advisors WARN）。`revoke execute ... from public, anon, authenticated`（它是 event trigger 的支撐函式，不該有任何 API 呼叫者）。
2. **default privileges 補洞**：M4 只涵蓋 tables；`alter default privileges in schema public revoke all on sequences from anon, authenticated;`＋`revoke execute on functions from anon;`（authenticated 是否保留 default execute 依「per-RPC 顯式 grant」慣例決定——建議一併 revoke，未來 RPC 逐支 grant，與 60_ 列舉式測試一致）。
3. `supabase/tests/60_default_privileges.sql` 擴充：斷言 sequences／functions 的 default ACL 與 rls_auto_enable 權限。
4. 部署後在雲端重跑 pg_default_acl／advisors 斷言（[LS-14](https://linear.app/little-sprout-app/issue/LS-14/部署-schema-到雲端-supabasedefault-privileges-覆核ddp) 的查詢可重用）。

## 已知限制（記錄，不在本票處理）

* `supabase_admin` 名下的 public default ACL 全開：postgres 身分無法修改，且非我們的物件建立路徑。接受風險，於 COLLABORATION §7 或 PLAN 註記。
