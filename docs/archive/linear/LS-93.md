## 來源

[LS-17](https://linear.app/little-sprout-app/issue/LS-17/storysign-in-with-appleemail-otp-登入) QA（2026-08-25）：本機 Supabase 預設 magic-link 信件模板不含明文 6 位 OTP，QA 只能用 GoTrue Admin API `/admin/generate_link`（service_role）取碼——可行但繞路，且 agent 需要 service_role key（`supabase status` 可得，本機專用）。

## 做法

* `supabase/config.toml` `[auth.email.template.magic_link]`（或 `otp`）指向 `supabase/templates/otp.html`，內容含 `{{ .Token }}`；本機 `supabase start` 生效，Inbucket 直接看到碼。
* 正式站模板另由 dashboard 設定（不在本票；§6 記一句）。
* qa.md 補一段「本機 OTP 取碼：Inbucket `http://127.0.0.1:54324`，信內 6 碼」。
* 反饋：`supabase/tests` 不涉；CI db job 不啟 Auth，無法驗——§7 標 ⚠️ 手動。

## 驗收

本機 `supabase start` 後 Email OTP 流程信件含 6 碼；qa.md 更新。hotfix 從 main。
