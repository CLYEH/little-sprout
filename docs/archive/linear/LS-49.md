## 描述

Phase 1 第 1／2／4 步的共同地基，**不含任何 SwiftUI 畫面**（畫面等 [LS-46](https://linear.app/little-sprout-app/issue/LS-46/設計定稿合併c-基準使用者指定調整-designlittlesproutpen) 定稿核可後另開票）。現況：`project.yml` 無任何 SPM package，app 尚未接 Supabase。

## 範圍

1. **SPM 依賴**：`supabase-swift`（pinned 版本）經 `project.yml` 加入（XcodeGen 漂移 gate [LS-13](https://linear.app/little-sprout-app/issue/LS-13/harnessxcodegen-漂移-gateprojectyml-xcodeproj-同步檢查) 要過）；CI macOS job 能 resolve。
2. **環境設定**：Supabase URL 與 publishable（anon）key 的載入方式——xcconfig／Info.plist／環境切換（local vs cloud）；用 supabase MCP（read-only）取得 project URL 與 publishable key。注意 `scan-secrets.sh` 是否誤判 anon key（它是可公開的，但若被掃到要走 [LS-10](https://linear.app/little-sprout-app/issue/LS-10/gate-強化secrets-誤判逃生口commit-驗證範圍排除保護分支歷史) 的逃生口並在 COLLABORATION 記錄理由，不得繞過）。
3. **Auth session 服務層**：`AuthService`（protocol＋Supabase 實作）：Sign in with Apple（先做介面與 nonce 流程，真實 capability 待 [LS-8](https://linear.app/little-sprout-app/issue/LS-8/phase-0-4註冊-apple-developer-program個人佔-bundle-id-與-app-名稱)）、Email OTP send/verify、session 持久化與刷新、登出。對照 `docs/API.md`（[LS-41](https://linear.app/little-sprout-app/issue/LS-41/api-契約成品化docsapimddocschema-對帳-gate) 進行中，先以 migrations 為準）。
4. **家庭／邀請 API client**：對 [LS-33](https://linear.app/little-sprout-app/issue/LS-33/taskls-18-後端-邀請加入申請與審核的-schemarpcrls)/37 的 RPC（create_family、create_invite、join_by_code、approve…以實際名稱為準）做型別化 client＋錯誤映射（k2Mw4 四層錯誤文法所需的錯誤分類在此層定義）。
5. **測試**：XCTest——AuthService 與 API client 用 protocol mock 測狀態機與錯誤映射；不打真網路。CI xcodebuild test 綠。

## 驗收

CI 全綠（xcodebuild test＋SwiftLint＋XcodeGen 漂移 gate）；handoff 附 API 對照表（client 方法 ↔ RPC）與尚未能驗證項（需 [LS-8](https://linear.app/little-sprout-app/issue/LS-8/phase-0-4註冊-apple-developer-program個人佔-bundle-id-與-app-名稱) 的 Apple capability）。
