## 來源

使用者 2026-08-26：「這個指令幫我放到 README」（demo 機刷新指令）。原本兩支腳本放在 gitignored 的 `.claude/worktrees/demo/`，README 不能指向不入版控的檔案 → 搬進 `scripts/ops/`。

## 內容

* `scripts/ops/demo-refresh.sh [ref]`：建／更新 detached worktree `.claude/worktrees/demo` 到 `origin/main`（可指定 `origin/test`）→ 缺 `Config/Secrets.xcconfig` 就從 `supabase status -o env` 產生本機值 → 建（或重用）`demo-iPhone17Pro` 模擬器 → build → install → launch；結尾印關機指令。路徑用 `git rev-parse --show-toplevel`，不寫死。
* `scripts/ops/demo-otp.sh <email>`：本機 GoTrue Admin API `generate_link` 取 6 碼 OTP（不寄信、不吃額度）；service_role 只從 `supabase status` 讀、不印出。
* `README.md` 新增「本機 demo」段：兩個指令＋前提（`supabase start`、Xcode）＋看完關模擬器。
* 由 orchestrator 直接做（harness 例外），hotfix 從 main、merge-reviewer（sonnet）、back-merge。
