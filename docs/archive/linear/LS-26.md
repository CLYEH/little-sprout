## 描述

來源：M1 設計稿 handoff。Pencil MCP 沒有 save 工具，編輯全在 app 記憶體，目標 .pen 檔一直是 0 bytes——本次靠複製 Pencil autosave backup（`~/.pencil/backup/<sha1>`）落地。每次 ui-designer 收工都會遇到。

## Scope

1. `scripts/gates/` 加 `design-landing-check.sh`：驗證 .pen 檔非空＋JSON 結構有效（version/themes/節點數），供 ui-designer 收工時執行。
2. ui-designer agent 定義補「收工程序」：落地（backup 複製法標準化）→ 跑落地檢查 → 檔案交 orchestrator 進版控。
3. docs/COLLABORATION.md §7 補列。
