## 現象

visual-reviewer／ui-designer／qa 的取證目錄（`ls46r7-review/`、`ls46r8/`、`ls46r2/`…）散落在各 worktree 根目錄、無命名慣例；`.gitignore` 無法機械擋，`tracked-ignored-check` 也管不到 untracked。目前靠 agent 自律不 `git add`——無 gate。

## 修法

1. 定固定位置：`.claude/evidence/<票號>/<輪次>/`（worktree 相對），根 `.gitignore` 加 `.claude/evidence/`。
2. 改 `.claude/agents/{ui-designer,visual-reviewer,qa}.md` 的截圖／掃描輸出存放指示指向該位置。
3. Gate：pre-commit 若 staged 檔案路徑符合 `*review*/`、`ls[0-9]*/`、`*.png` 在非 `design/`／`LittleSprout/Assets` 路徑 → 擋（正負對照測試）。

## 驗收

* 派一次 visual-reviewer，取證落在 `.claude/evidence/`，`git status` 乾淨。
* 人造 `git add ls99r1/x.png` 被 pre-commit 擋。
* COLLABORATION §7 加列。
